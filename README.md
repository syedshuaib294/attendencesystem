# Student Attendance System (React + Bootstrap)

Teacher view: mark Present / Late / Absent by date, search, bulk-mark, add/remove students, class progress.
Student view: pick a student to see attendance %, counts, 4-week heatmap, filterable records and a 75% target helper.

Data lives in React state only (no localStorage), so it resets on refresh. Sample data is generated in `src/App.jsx`.

## Run
1. Install Node.js 18+
2. `npm install`
3. `npm run dev` -> open http://localhost:5173
